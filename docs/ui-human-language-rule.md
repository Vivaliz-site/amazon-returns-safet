# Regra de linguagem da interface

Toda interface voltada ao usuário deve usar português claro, simples e operacional.

Estados internos, enums, nomes de campos, códigos de erro, nomes de jobs/workers, versões, flags, nomes técnicos de integrações e outros detalhes de implementação pertencem ao backend, logs e auditoria técnica.

A interface deve traduzir essas informações para dizer somente: o que aconteceu, o que já foi verificado, o que falta confirmar, qual é a próxima ação, valores, datas, rastreios, mensagens trocadas e prazos relevantes.

Revisões humanas devem existir apenas quando houver dúvida real. A tela de revisão deve mostrar as mensagens trocadas e explicar de forma objetiva por que a decisão do usuário é necessária.
