# Approved Amazon BR policy matrix and evidence-based routing

Approved by the owner in this chat on 2026-09-05. Supersedes every global D+75 assertion and the abandoned all-program D+45 draft.

## Rules
- STANDARD return-not-received threshold: 45 days using the existing financial basis; final Seller Central eligibility remains authoritative.
- FBA_ONSITE and DELIVERY_BY_AMAZON: orders from 2026-04-21 require 60 days after customer refund; earlier orders use 45 days. Missing order date must block automatic classification.
- Classic FBA is not the seller-fulfilled SAFE-T route.
- Threshold is not an action: classify official return/transport evidence before preparing a first claim.
- Confirmed return-to-seller flow: SAFE_T_SUBMIT only with refund/exposure/eligibility evidence and no existing claim.
- Lost, undeliverable, refused, carrier-damaged/disposed: monitor proactive reimbursement first where the logistics policy applies; compare explicit promise or applicable financial deadline. Refresh Finances before escalation.
- Physical discrepancy: evidence review, not a non-return claim. Carrier delivery is not proof of warehouse receipt and may start a distinct 7-calendar-day claim window.
- Existing claims retain their actual lifecycle. A resolved claim appeal has a 5-business-day window; prefer explicit official deadline. Missing or expired deadline must not silently generate an appeal.
- Historical sent review/support evidence suppresses duplicate submissions. Interpret replies before selecting a response, support, wait or human review.
- Approval, promise and denial are not financial credit. RECOVERED requires current released reconciled credit.

## Safety and rollout
Preserve prior artifacts and disabled legacy runtime; do not overwrite other worktrees. Keep all six external write flags false until each channel has evidence-backed acceptance. Never infer receipt, sender authentication, holiday calendar or financial success from an unverified string.
Use pure policy/routing functions, tenant-scoped existing repositories and private journal audit; add no public financial endpoint.
